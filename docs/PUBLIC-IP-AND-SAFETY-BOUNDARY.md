# Public IP & Safety Boundary

This repository is the public-facing expression of the Global Domain System (GDS). It is intended to explain the public concept without publishing protected implementation or confidential extensions.

Public visibility does not by itself transfer ownership, place the work in the public domain, waive intellectual-property rights, or grant unrestricted permission to reproduce, commercialise, modify or redistribute protected material.

The creator has stated that GDS was created by Megan Robyn Samson and is intended to be licensed to SheMesh Tribe LLC. This notice records the intended boundary; it is not itself a legal assignment or licence.

Do not publish here:

- protected or unpublished methodology sufficient to reconstruct confidential extensions;
- private implementation, source code or internal machinery;
- unpublished inventions or patent-sensitive details;
- private datasets or personal information;
- credentials, keys, passwords or access tokens;
- confidential commercial agreements or partner information; or
- private pilot credentials/access codes.

Keep detailed development records, original masters, protected extensions and licensing documents in a controlled private location.

If protected or secret material is accidentally published, remove it from the current public tree, preserve an incident record, and rotate/revoke exposed credentials. Removal from the current tree does not necessarily remove material from Git history or copies held by others.
